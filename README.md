# 🖥️ Basic Projects

A collection of frontend projects built with pure HTML, CSS and JavaScript.
No frameworks. No libraries. Just clean Vanilla JS.

---

## 📁 Projects

---

### 🖼️ Image Editor
A fully functional browser-based image editor built from scratch.

**Features:**
- 9 real-time filter sliders — brightness, contrast, saturation, blur, hue rotation, grayscale, sepia, opacity, invert
- 17 presets inspired by Instagram (Clarendon, Lark, Juno, Reyes, Gingham) and Snapchat filters
- Download edited image instantly as PNG
- Reset all filters to default in one click

**Tech used:**
- HTML5 Canvas API
- CSS3 Custom Properties
- Vanilla JavaScript — DOM manipulation, CSS filters

---

### 🐍 Snake Game
A classic Snake Game built entirely from scratch with no game libraries.

**Features:**
- Dynamic grid system built using nested for loops
- Real-time snake movement using array unshift + pop logic
- Food collision with random spawning
- Snake grows when food is eaten
- Wall collision detection — Game Over on hit
- Live score system — increases by 10 per food eaten
- High score saved in localStorage — persists after closing browser
- Live timer running in parallel
- Full restart system — resets everything cleanly
- Keyboard controls using Arrow Keys

**Tech used:**
- HTML5
- CSS3 Grid
- Vanilla JavaScript — setInterval, DOM manipulation, localStorage, event listeners

---

### 📋 Kanban Board
A drag and drop task management board — like a personal to-do list with organized columns.

**Features:**
- Add tasks to different columns — To Do, In Progress, Done
- Drag and drop tasks between columns
- Delete tasks
- Clean and minimal UI

**Tech used:**
- HTML5 — Drag and Drop API
- CSS3 — Flexbox, Custom Properties
- Vanilla JavaScript — DOM manipulation, event listeners
